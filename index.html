RAG Retriever Comparison

This app demonstrates differences between different forms of retrieval architecture for RAG models. The user uploads a PDF which is stored in vector database. After embedding the file, the app allows the user to experiment with three different configurations for generating answers based on user queries. The app can help clarify which architecture is most useful for a particular set of documents and for specific domain expertise.
